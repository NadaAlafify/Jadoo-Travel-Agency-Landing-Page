# Jadoo - Modern Travel Agency Landing Page 

##  Description
**Jadoo** is a visually stunning, pixel-perfect travel agency landing page. This project is a practical core challenge focused on recreating a complex, modern UI design from scratch. 

It highlights advanced positioning, complex multi-card layouts, and refined styling practices tailored for modern web applications.

##  Live Demo
Explore the live website here: (https://nadaalafify.github.io/Jadoo-Travel-Agency-Landing-Page/)

##  Tech Stack
- **HTML5:** Structuring high-end landing page sections with deep nested components and semantic layouts.
- **CSS3 (Pure CSS):** Leveraging advanced properties including dynamic layout tools, precise relative/absolute positioning for floating cards, and custom color variables.

##  Key Features & Styling Outcomes
- **Hero & Navigation Panel:** Clean, sleek header with an integrated login button and a smooth color layout.
- **Service Categories:** A symmetric row grid showcasing service icons with elegant hover transformations.
- **Top Destinations:** Beautiful image cards wrapped with custom text spacing, navigation cues, and shadows.
- **Interactive Booking Widget:** A complex floating card layout displaying trip info, custom badge styling, and layered box-shadows.
- **Framework-Free Layout:** Written 100% manually to reinforce logical layout distribution, element layering, and pure styling execution.
